# คลังหน้าที่สำเร็จรูป

**ไม่ต้องเลือกเองก็ได้** — เจ้าของพิมพ์ `OWNER_CODE` หาบอท แล้วเล่าในแชทว่าทำธุรกิจอะไร บอทจะหยิบแบบที่ใกล้ที่สุดในโฟลเดอร์นี้มาเป็นโครง ร่างให้ดูก่อนพิมพ์ `ยืนยัน`

อยากเขียนเป็นไฟล์เอง: เลือกแบบที่ใกล้ธุรกิจที่สุด ก๊อปเป็น `brief.txt` แล้วแก้ทุกช่อง `〔...〕` ให้เป็นข้อมูลจริง

```bash
cp briefs/online-shop.txt brief.txt
```

| ไฟล์ | เหมาะกับ | บอทช่วยอะไร |
|---|---|---|
| [`online-shop.txt`](online-shop.txt) | ร้านขายของออนไลน์ | ตอบราคา คิดยอดรวมพร้อมค่าส่ง รับที่อยู่ รับสลิป |
| [`restaurant.txt`](restaurant.txt) | ร้านอาหาร คาเฟ่ | เมนู ราคา เวลาเปิด ที่จอดรถ สั่งกลับบ้าน |
| [`dorm.txt`](dorm.txt) | หอพัก ห้องเช่า คอนโดปล่อยเช่า | ห้องว่าง ค่าเช่า ค่าแรกเข้า รับเรื่องนัดดูห้อง |
| [`beauty-salon.txt`](beauty-salon.txt) | ร้านทำผม ทำเล็บ สปา | บริการ ราคา รับเรื่องอยากจองคิว ดูรูปแบบที่ลูกค้าส่งมา |
| [`tutor.txt`](tutor.txt) | คอร์สเรียน ติวเตอร์ | แนะนำคอร์สตามระดับชั้น วิธีสมัคร รับสลิป |
| [`home-service.txt`](home-service.txt) | ช่างแอร์ ซ่อมบ้าน ทำความสะอาด | ถามอาการ ขอรูปหน้างาน ราคาเริ่มต้น รับเรื่องนัดช่าง |
| [`personal-secretary.txt`](personal-secretary.txt) | เลขาส่วนตัวของเจ้าของ | จดงาน ถอดเสียง อ่านเอกสาร สรุปวันนี้ ร่างข้อความ |

ไม่มีแบบไหนใกล้เลย → ใช้ [`../brief.example.txt`](../brief.example.txt) ซึ่งเป็นโครงเปล่า 4 หัวข้อ

## เคล็ดลับ

- **ช่อง `〔...〕` ที่ลืมแก้** — ระบบเตือนตอนบูตและตอน `npm run chat` และบอทจะไม่พิมพ์ช่องนั้นให้ลูกค้าเห็น
- **เขียนเท่าที่จำเป็น** — ทุกข้อความที่บอทตอบต้องส่งคำสั่งนี้ไปด้วย ยิ่งยาวยิ่งเปลือง (รับได้ไม่เกิน 8,000 ตัวอักษร)
- **ข้อมูลที่ไม่ได้เขียน บอทจะไม่เดา** — อยากให้ตอบเรื่องไหน ต้องเขียนเรื่องนั้นไว้
- **แก้ทีหลังผ่าน LINE ได้** — ตั้ง `OWNER_CODE` แล้วพิมพ์สั่งในโหมดเจ้าของ เช่น "แก้ราคาคุกกี้เป็น 130" หรือส่งรูปเมนูใหม่ให้ปรับ
